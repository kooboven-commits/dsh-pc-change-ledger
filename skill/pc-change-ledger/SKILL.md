# 电脑改动账本

同一台电脑上可能同时有好几个 AI 助手（Codex、DeepSeek、Claude……）在干活。改完系统设置就忘、互相不知道对方改了什么、出了问题没人能还原，是用户最常见的噩梦。

这个技能给所有助手**一本共用的账本**：`%USERPROFILE%\.agents\change-ledger\ledger.jsonl`。每次改系统设置都要记下“改了什么、为什么、原来是什么、怎么撤销”，任何一个助手都能查、都能撤。

工具是本技能目录下的 `scripts/ledger.ps1`（Windows PowerShell 5.1 自带即可）：

```powershell
powershell -NoProfile -ExecutionPolicy Bypass -File "<本技能目录>\scripts\ledger.ps1" <命令> [参数]
```

先设置你是谁，账本里会显示：`$env:LEDGER_AGENT = 'codex'`（或 `deepseek`、`claude`）。

## 什么算“系统改动”（都要记账）

- 注册表（任何 `HKCU:` / `HKLM:` 下的值）
- 电源：休眠、快速启动、电源计划、睡眠时间
- 虚拟内存 / 分页文件
- 开机自启（Run 键、启动文件夹）、计划任务、系统服务的启动类型
- 用户或系统环境变量（包括 PATH）
- Windows 更新策略、防火墙规则、Defender 设置、hosts 文件、代理设置
- 安装、卸载软件或驱动
- 删除或移动**项目文件夹以外**的文件（下载文件夹、桌面、AppData、Program Files……）

只读查看（看配置、看占用、看日志）不用记账。

## 流程：每次改系统设置都走这 6 步

### 1. 先查账
```powershell
ledger.ps1 list
```
看看最近其他助手改过什么。用户说“电脑出问题了”，**第一件事就是查账**，很可能就是最近某次改动造成的。

### 2. 判断风险，高风险先问用户
下面这些**必须先用大白话告诉用户后果、等用户同意**再动手，用户说“帮我清理/优化”不等于同意了这些：

| 改动 | 必须告诉用户的后果 / 必须先检查的事 |
|---|---|
| 虚拟内存挪到别的盘、改小 | 先看目标盘有没有 BitLocker：`manage-bde -status D:`。**开机自动解锁的加密盘，在创建分页文件时还没解锁**，分页文件建不出来 → 内存额度不够 → 程序成片崩溃。判断要不要改小，看“提交内存”（`Get-Counter '\Memory\Committed Bytes'`），**不要看分页文件的实际占用**，占用小不代表能删 |
| 关闭休眠 `powercfg /h off` | 同时会关掉“快速启动”，开机变慢；有些人每天都在用休眠 |
| 删除系统还原点 / 卷影副本 | **无法撤销**；只剩一个时删掉就没法回滚了 |
| 停用 Windows 更新、Defender、防火墙 | 安全风险 |
| 禁用服务、删开机自启、删计划任务 | 可能让某个软件失灵（输入法、驱动面板、同步盘） |
| 改 hosts、代理、DNS | 可能让网络或某些网站打不开 |
| 卸载软件 | 用户的数据可能跟着没了 |
| 删除项目以外的文件 | **无法撤销**，先移到回收站或备份文件夹 |

低风险的（比如清理临时文件夹、改一个自己刚加的环境变量）可以直接做，但照样记账。

### 3. 大范围改动前先拍快照
一次要改好几项、或者要装/卸软件时：
```powershell
ledger.ps1 capture -Name before-清理C盘
```
快照会记下电源、虚拟内存、开机自启、服务、计划任务、用户环境变量、更新策略、hosts、已安装软件。

### 4. 用账本工具去改（它会自动记下旧值和撤销命令）
```powershell
# 注册表
ledger.ps1 reg-set -Path 'HKCU:\Software\Xxx' -Name Foo -Value 1 -Type DWord -Why '原因（给用户看的话）' -Risk low
# 用户环境变量（-Value '' 表示删除）
ledger.ps1 env-set -Name HF_ENDPOINT -Value 'https://hf-mirror.com' -Why '原因'
```
其他改动用你自己的命令去做，**做完马上**手动记账，并且自己写好撤销命令：
```powershell
ledger.ps1 record -What '关闭休眠（hiberfil.sys 6 GB）' -Undo 'powercfg /h on' -Verify 'powercfg /a' -Risk high -Why '用户同意腾出 C 盘空间'
```
- `-Undo` 必须是一条能直接运行、能恢复原状的 PowerShell 命令。动手前先把旧值读出来写进去，**不要凭记忆写默认值**
- 真的无法撤销（删还原点、删文件）就写 `-Undo NONE`，并在 `-What` 里说清楚
- 需要管理员权限的改动，撤销时通常也需要管理员权限，在 `-What` 里注明

### 5. 验证实际效果，不是只看设置写进去了
- 读回设置值只能说明“写进去了”，要再看**实际效果**：文件真的变小了吗？服务真的停了吗？程序还能正常启动吗？
- **要重启才生效的改动**（虚拟内存、部分电源和驱动设置）：告诉用户“重启后让我再检查一次”，重启后第一件事就是验证；发现不对立刻撤销
- 改完如果出现异常（程序崩溃、系统日志报错、网络不通），先怀疑刚才的改动

### 6. 告诉用户
用用户的语言说清楚：改了什么、为什么、编号是几号、怎么撤销。例如：

> 已关闭休眠，腾出 6 GB（账本 #12）。想恢复的话跟我说“撤销 12”，或者运行 `ledger.ps1 undo -Id 12 -Yes`。

## 撤销

```powershell
ledger.ps1 show -Id 12          # 看详情
ledger.ps1 undo -Id 12          # 先预览要执行的撤销命令
ledger.ps1 undo -Id 12 -Yes     # 真的撤销
```
- 同一个设置被改过好几次时，必须**从新往旧**撤，工具会拦住错误的顺序
- 撤销前把要执行的命令给用户看一眼；涉及管理员权限的，需要用户允许提权

## 用户问“到底改了什么”时

1. `ledger.ps1 list` 看账本
2. 有快照就对比：`ledger.ps1 diff -From before-清理C盘`（不写 `-To` 就是和现在比）
3. `ledger.ps1 snapshots` 列出所有快照
4. 账本里没有、快照也对不上的改动，说明有人没记账：老实告诉用户，不要猜

## 规矩

- 账本是给**用户**看的：`-Why`、`-What` 用用户的语言写，写人话
- 不要为了“顺手优化”去改用户没要求的系统设置
- 不要删除或改写账本里已有的记录；记错了就再记一条更正
- 账本只存设置的名字和值，**不要把密码、密钥、令牌写进去**
